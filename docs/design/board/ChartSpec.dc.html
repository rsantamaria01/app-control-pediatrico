Comportamiento

Ejes0–5 años: X en meses. 5–19 años: X en años. Peso/longitud-talla: X en cm. Y = valor con unidad.
Zoom / panEscritorio y tablet: dataZoom inside (rueda + arrastre) + slider de 24 px; botón «Restablecer». 375 px: sin slider; rango por defecto = edad actual ±6 meses; selector «6 m · 1 a · Todo».
SelecciónClic / toque en punto: emphasis (radio 5 + halo), tooltip fijo; en la tabla se resalta la misma fila.
TooltipFecha · edad (y «edad corregida» si aplica) · valor con unidad · Z. Si tiene nombre OMS, el chip lo muestra (p. ej. «Talla baja · −2,41»). Padres: valor, Z y «dentro / fuera del rango esperado».
Indicadores0–5 a: talla/longitud, peso, peso/longitud-talla, IMC y perímetro cefálico. 5–19 a (OMS 2007): talla, IMC y peso (hasta 10 a).
EtiquetasChip de sexo «Niña» / «Niño» en gris neutro, nunca rosa/azul. Prematuros < 24 m: chip «Edad corregida» y eje «Edad corregida (meses)».
Accesibilidadaria.enabled: true, descripción generada; alternativa siempre disponible: «Ver tabla».
DatosCurvas desde columnas SD precalculadas de las tablas OMS; Z del paciente con LMS (correctZ).

  aria: { enabled: true },
  textStyle: { fontFamily: 'Inter', fontSize: 11 },

  xAxis: { type: 'value', name: 'Edad (meses)', min: 0, max: 24, interval: 3,
           axisLine: { lineStyle: { color: c.axis } }, splitLine: { lineStyle: { color: c.grid, type: 'dashed' } } },
  yAxis: { type: 'value', name: 'Peso (kg)', splitLine: { lineStyle: { color: c.grid } } },
  dataZoom: isDesktop ? [{ type: 'inside' }, { type: 'slider', height: 24 }] : [{ type: 'inside', zoomOnMouseWheel: false }],
  tooltip: { trigger: 'item', confine: true, borderColor: c.border, backgroundColor: c.bg, formatter: tooltipFmt },
  series: [
    ...sdBands(c),                       // 'line' stack + areaStyle, silent: true, symbol: 'none'

    { type: 'line', name: 'Paciente', data: patient, symbolSize: 7, z: 10,
      lineStyle: { width: 2.5, color: c.patient }, itemStyle: { color: c.bg, borderColor: c.patient, borderWidth: 2 },
      emphasis: { scale: 1.6, itemStyle: { color: c.patient } }, selectedMode: 'single' }
  ]
